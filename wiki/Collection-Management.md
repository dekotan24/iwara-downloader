# コレクション管理

## UUID タグの埋め込み

iwara が各動画ファイルに割り当てる UUID（file_id）を、ダウンロードした mp4 ファイルの MPEG-4 タグに埋め込みます。

- ネームスペース: `com.iwara`、キー: `video_id`, `file_id`
- TagLibSharp を使用して QuickTime Apple Tag の free-form atom に書き込み
- ファイル名や DB が変わっても、ファイル自体から UUID を読み取って重複 DL を防止

## ツールメニュー

| メニュー | 説明 |
|----------|------|
| URL 一括インポート... | URL リストから一括取り込み |
| iwara 検索インポート... | iwara の検索結果を取り込み |
| フォルダから取り込み... | ローカルフォルダの動画ファイルを DB に登録 |
| 重複チェック... | UUID やファイル情報に基づいて重複を検出 |
| 未移動ファイルの一括移動... | 保存先変更時に移動できなかったファイルを再移動 |
| 移動済みファイルの再リンク... | 外部ツール（FastCopy 等）で移動したファイルのパスを DB に追従 |
| ローカルファイル整合性チェック... | DB の記録と実ファイルの食い違いを検出 |
| 統計ダッシュボード... | ダウンロード統計の表示 |
| DB操作ツール(上級者向け)... | [DB 操作ツール](Database-Tool) を起動（設定でオンにした場合のみ表示） |

## 保存先の変更とファイル移動

設定画面またはチャンネルの右クリックメニューから保存先を変更できます。

- 変更時にディスク容量チェックが行われます
- ファイル移動は進捗表示付きで実行されます
- ジャーナル方式で移動処理を記録し、クラッシュ・強制終了からも自動復旧します
  - 移動開始前に `start` エントリを記録
  - 完了後に `done` エントリを記録
  - 起動時に不完全な移動があれば自動で復旧
- ジャーナルファイル: `%APPDATA%\IwaraDownloader\move_journal.jsonl`

## 移動済みファイルの再リンク

FastCopy 等の外部ツールでファイルを別のフォルダに移動した場合、「移動済みファイルの再リンク」を使って DB のパスを追従させることができます。ファイルサイズと UUID で照合・検証します。

## ファイル名テンプレート

設定画面でダウンロード時のファイル名テンプレートを指定できます。

| 変数 | 例 |
|------|-----|
| `{title}` | My Video |
| `{author}` | username |
| `{date}` | 20250101（投稿日） |
| `{id}` | AbCdEfGh |
| `{quality}` | Source |

デフォルト: `{id}_{title}`

「DL 済みファイルを一括リネーム」ボタンで、テンプレート変更後に既存ファイルをまとめてリネームすることもできます。

## 既存ファイルへのメタデータ移行

設定のバックアップタブから、過去にダウンロードした動画ファイルに iwara の UUID タグを書き込むことができます。タグを書き込むと、DB が消えた場合やファイル名変更後でもファイルを再発見できます。
