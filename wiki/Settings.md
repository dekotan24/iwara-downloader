# 設定一覧

設定画面は以下のタブで構成されています。

## 一般タブ

### ダウンロード設定

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| 保存先フォルダ | `%USERPROFILE%\Videos\Iwara` | 動画の保存先 |
| デフォルト画質 | Source | Source / 540p / 360p |
| 同時DL数 | 2 | 1〜3 |
| リトライ回数 | 3 | 失敗時の自動リトライ回数 |
| サムネ保存先 | Roaming | Roaming（`%APPDATA%` 配下）/ DL先配下 |
| 空き容量下限 | 1 GB | この容量を下回ると DL を開始しない（0 = 無効） |

### 自動チェック

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| 新着を自動でチェック | ON | |
| 間隔 | 60 分 | 30 / 60 / 120 / 360 / 720 / 1440 分から選択 |
| 新着検出時に自動でDL開始 | ON | |
| iwara外動画もDLする | OFF | YouTube 埋め込み等。チャンネル別に上書き可 |

### 通知・起動

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| トースト通知を有効化 | ON | DL 完了・新着検出・エラー等の通知 |
| 起動時に最小化 | OFF | |
| 閉じるボタンでトレイに最小化 | ON | |

## アカウントタブ

### Python 環境

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| Python パス | python | セットアップウィザードで設定される |
| yt-dlp パス | yt-dlp | 未インストールなら自動で `pip install` を試行 |

### iwara アカウント

| 項目 | 説明 |
|------|------|
| メールアドレス | iwara.tv のログイン用メールアドレス |
| パスワード | DPAPI で暗号化して保存 |
| 再ログイン | メールアドレス/パスワード変更後に押す |

## 詳細設定タブ

### レート制限設定

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| API リクエスト間隔 | 1000ms | API 呼び出しの間隔 |
| ダウンロード間隔 | 3000ms | DL 完了後の待機時間 |
| チャンネル巡回間隔 | 5000ms | チャンネルチェック時の間隔 |
| ページ取得間隔 | 500ms | ページング時の待機時間 |

プリセットボタンで「控えめ」「標準」「積極的」の 3 段階に一括設定できます。

### エラー時の動作 (429/403)

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| 基本待機時間 | 30000ms | 429/403 エラー時の基本待機時間 |
| 最大待機時間 | 300000ms | バックオフの上限 |
| エクスポネンシャルバックオフ | ON | 連続エラー時に待機時間を倍々に増加 |

## データベースタブ

### DB 操作ツール (上級者向け)

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| ツールメニューにDB操作ツールを表示する | OFF | ON にするとツールメニューに「DB操作ツール(上級者向け)...」が追加される |

詳細は [DB 操作ツール](Database-Tool) を参照してください。データベースを直接編集できるため、通常の操作で解決できない場合の最終手段として使ってください。

## その他タブ

### 効果音

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| DL 完了時に音を鳴らす | OFF | 音声ファイルを指定 |
| DL 失敗時に音を鳴らす | OFF | 音声ファイルを指定 |

### ファイル名テンプレート

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| テンプレート | `{id}_{title}` | 使用可能変数: `{title}`, `{author}`, `{date}`, `{id}`, `{quality}` |
| DL 済みファイルを一括リネーム | — | テンプレート変更後に既存ファイルをリネーム |

### メタデータ

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| メタデータ(.json)を保存 | OFF | 動画と一緒に JSON メタデータファイルを保存 |

### 起動時の動作

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| 起動時に更新をチェック | ON | GitHub Releases から最新版を確認 |
| 未完了のDLを再開 | ON | 前回の未完了タスクを自動で再開 |

## バックアップタブ

### エクスポート / インポート

| 項目 | 説明 |
|------|------|
| 設定をエクスポート | パスワードを除外して設定を JSON で書き出し |
| 設定をインポート | JSON から設定を読み込み（パスワードは維持） |
| 購読リストをエクスポート | 購読チャンネルのリストを書き出し |
| 購読リストをインポート | 購読チャンネルのリストを読み込み |

### 既存ファイルのメタデータ移行

| 項目 | 説明 |
|------|------|
| 既存ファイルにタグを書き込む | 過去 DL 済みの mp4 に UUID タグを書き込み |
| サムネ URL を一括補完 | サムネイル URL が未取得の動画を補完 |

## 設定ファイルの場所

```
%APPDATA%\IwaraDownloader\settings.json
```

JSON 形式で保存されます。書き込みは一時ファイル経由のアトミック置換で行われ、書き込み中のクラッシュによる破損を防ぎます。
