# DB 操作ツール（上級者向け）

データベースを直接操作するメンテナンス用のツールです。SQL の実行、テーブルの直接編集、状態の一括復旧ができます。

> [!WARNING]
> 誤った SQL や編集はデータの破損・消失につながります。動画ファイル自体は連動して変更されないため、DB と実ファイルが食い違う原因にもなります。通常の操作で解決できない場合の最終手段として使ってください。

## 起動方法

1. 設定 →「データベース」タブで **「ツールメニューにDB操作ツール(SQLエディタ/テーブルブラウザ)を表示する」** をオンにする
2. ツールメニュー →「DB操作ツール(上級者向け)...」

本体とは別プロセスの独立した実行ファイル（`DBMaintenanceTool.exe`）として起動します。表示言語は本体の設定（`settings.json` の `Language`）に従います。

### IwaraDownloader を終了してから使う

本体が起動中だと、裏で動くダウンロード処理と DB 書き込みが競合し、メモリ上のタスク状態と DB の内容がズレる可能性があります。ツールは本体のプロセスを検出すると警告を出しますが、**本体を終了してから使うことを強く推奨します**。

## 読み取り専用モードと書き込みモード

起動直後は必ず**読み取り専用モード**です。画面上部のバナーで現在のモードを確認できます。

書き込みモードに切り替えると、強制バックアップが作成されてから有効になります。バックアップに失敗した場合は書き込みモードを開始しません。

読み取り専用の保証は SQL 文の内容を判定して行っているのではなく、**読み取り専用接続（`Mode=ReadOnly`）で開くことで SQLite 自身に書き込みを拒否させています**。そのため `UPDATE` 等を書いても実行される心配はありません。

読み取り専用モードに戻すのは常に安全な方向なので、確認ダイアログは出ません。

## SQL 実行タブ

SQL を入力して `F5` または「実行 (F5)」で実行します。

- 読み取り専用モードでは `SELECT` の結果のみが返り、書き込み系は自動的に拒否されます
- 「最大取得件数」で結果の上限を設定できます。上限に達した場合はその旨が表示されます

## テーブルブラウザタブ

テーブルを選んで中身を一覧・編集できます。

- 書き込みモード中のみ、セルの編集と行の削除ができます
- **主キーが無いテーブルは閲覧のみ**です（どの行を更新すべきか一意に決められないため）

## 復旧タブ

本体アプリの起動時レジューム相当の復旧を、アプリを再起動せずに一括で行います。書き込みモードを有効にしてから使用してください。

| 操作 | 用途 |
|------|------|
| ダウンロード中 → 待機中に戻す | 異常終了で「ダウンロード中」のまま固まった行の復旧 |
| 失敗 → 待機中に戻す | リトライ回数とエラーもリセットして再挑戦させる |
| 一時停止 → 待機中に戻す | 「後で」保存した分の一括再開 |

実行前に対象件数が表示され、確認ダイアログを経てから適用されます。

## 整合性の警告

`Videos` と `ExcludedVideos` の両方に同じ動画が存在する場合、画面に警告が表示されます。この 2 つのテーブルは「どちらか一方にのみ存在する」という不変条件を持つため、両方に現れるのは想定外の状態です。

## バックアップ

書き込みモードへの切り替え時に作成される強制バックアップのほか、本体が日次で自動バックアップ（最大 7 世代）を作成しています。

```
%APPDATA%\IwaraDownloader\backups\
```

操作を誤った場合は、アプリを終了した状態でバックアップから `data.db` を戻してください。
