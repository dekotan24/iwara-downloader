# Web メディアサーバー

アプリに内蔵された Web サーバーを起動すると、LAN 内のブラウザから動画を視聴・管理できます。

> ⚠️ LAN 内公開を想定しています。インターネットへの直接公開はしないでください。

## セットアップ

1. 設定 →「メディアサーバー」タブを開く
2. ポートを設定（デフォルト: 7860）
3. 認証を設定（ユーザー名・パスワード）
4. 「LAN内の他デバイスからのアクセスを許可」を必要に応じて ON/OFF
   - ON: `0.0.0.0` でバインド（同じネットワーク内の他デバイスからアクセス可）
   - OFF: `127.0.0.1` でバインド（このPC のみ）
5. サーバーを開始すると、アクセス URL が表示される

「起動時に自動開始」を ON にすると、アプリ起動時にサーバーも自動で起動します。

## 機能

- ストリーミング再生（HTTP Range によるシーク対応）
- プレイリスト / 連続再生 / シャッフル
- 検索（スペース区切り AND）/ ソート
- グリッド / リスト表示切替
- チャンネル別表示
- お気に入りの登録 / 解除
- エラー動画の再試行
- DL キュー状況・統計

## キーボードショートカット（プレーヤー）

| キー | 機能 |
|------|------|
| `Space` | 再生 / 停止 |
| `←` `→` | 10 秒シーク |
| `↑` `↓` | 音量 |
| `F` | フルスクリーン |
| `N` / `P` | 次 / 前の動画 |

## 認証

- ユーザー名 + パスワードで認証
- パスワードは DPAPI で暗号化保存
- セッション有効期間: 24 時間

## サーバー設定項目

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| ポート | 7860 | 1024〜65535 の範囲 |
| LAN 公開 | ON | OFF にするとローカルのみ |
| ユーザー名 | admin | |
| パスワード | (空) | |
| 自動開始 | OFF | アプリ起動時に自動でサーバー開始 |
