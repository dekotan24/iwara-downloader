# 基本的な使い方

## 画面構成

- **左側ツリービュー**: カテゴリ・チャンネル一覧
- **右側リストビュー**: 動画一覧（詳細リスト / サムネタイル表示に切替可）
- **上部**: ツールバー、URL 入力欄、検索ボックス、NSFW フィルタ
- **下部ステータスバー**: DL 中 / 待機 / 完了件数、空き容量

### ツリービューのカテゴリ

| カテゴリ | 内容 |
|----------|------|
| 全ての動画 | 登録済みの全動画 |
| ⭐ お気に入り | お気に入りに登録した動画 |
| ダウンロードキュー | DL 中または DL 待ちの動画 |
| DL済 | ダウンロード完了済み |
| スキップ | スキップされた動画 |
| エラー | ダウンロードに失敗した動画 |
| 🚫 除外済み | 削除して除外リスト（ゴミ箱）へ移した動画 |
| (各チャンネル) | 購読したユーザーごとの動画 |

## チャンネル購読

URL 入力欄にユーザー名またはプロフィール URL を入力して Enter で追加します。

- `username` のみの入力でも可
- `https://www.iwara.tv/profile/username` 形式でも可
- `https://www.iwara.ai/profile/username` にも対応

追加すると動画一覧の取得が始まります。取得完了後、自動チェックが有効なら定期的に新着をチェックします。

### チャンネルの右クリックメニュー

| メニュー | 説明 |
|----------|------|
| ページを開く | iwara のプロフィールページをブラウザで開く |
| 今すぐ確認 | 新着を即座にチェック |
| 全てダウンロード | 未 DL の動画をすべてキューに追加 |
| Not Found を除外 | エラー一覧選択時のみ表示。404 動画を除外 |
| ファイル存在チェック | DL 済みファイルのローカル存在を検証 |
| 保存先を変更... | このチャンネル専用の保存先を設定 |
| iwara外動画のDL | YouTube 埋め込み等の DL 設定（デフォルトに従う / DLする / DLしない） |
| 有効にする / 無効にする | 自動チェックの対象にするかどうか |
| 削除 | チャンネル登録を削除 |

## ダウンロード

### 方法

- **チャンネルから**: 動画を選択して右クリック →「ダウンロード」
- **単発**: URL 入力欄に動画 URL（`https://www.iwara.tv/video/xxxxx`）を入力して Enter
- **クリップボード監視**: ツールバーで ON にすると、iwara URL をコピーするだけで自動追加
- **一括インポート**: ツールメニューから URL リスト / 検索結果 / ローカルフォルダから取り込み

### 動画の右クリックメニュー

項目は選択中の動画の状態に応じて出し分けられます。よく使う操作ほど上に並びます。

**その動画に対して今できる主な操作**

| メニュー | 表示される条件 |
|----------|--------------|
| 再生 | 完了済みでローカルファイルが存在する |
| フォルダを開く | ローカルファイルが存在する |
| ダウンロード | 未 DL / 失敗など、DL 可能な状態（失敗を含む選択では「ダウンロード (失敗をリトライ含む)」） |
| キャンセル | 待機中 / DL 中 / 一時停止中 |

**メンテナンス操作**

| メニュー | 説明 |
|----------|------|
| 失敗を再試行 | 失敗したタスクをリトライ |
| 再ダウンロード... | 完了済みの動画を再度 DL |
| 情報再取得 | タイトル等のメタ情報を iwara から再取得 |
| ファイル存在チェック | ローカルファイルの存在を検証 |
| ローカルファイルをマップ... | 手元にあるファイルを、この動画の実体として結び付ける |
| 優先度 | 待機中の動画のキュー順を変更（最優先 / 優先 / 普通 / 低） |

**開く・コピー**

| メニュー | 説明 |
|----------|------|
| ページを開く | iwara の動画ページをブラウザで開く |
| 投稿者のページを開く | 投稿者のプロフィールページを開く |
| URLをコピー / タイトルをコピー / 投稿者名をコピー | それぞれクリップボードへコピー |

**その他**

| メニュー | 説明 |
|----------|------|
| お気に入りに追加 / お気に入りから削除 | お気に入り登録のトグル |
| 詳細情報... | 動画の詳細情報（メタデータ、タグ、メモ）を表示・編集 |
| 削除 | 除外リスト（ゴミ箱）へ移動。DL 済みのファイルは削除される |

除外済みノードを選択している場合は、代わりに **復元**（一覧へ戻す）と **完全に削除**（DB から完全に削除、取り消し不可）が表示されます。

> [!NOTE]
> 「削除」は除外リストへの移動と同時に DL 済みのファイルを削除します。除外リストから項目を戻すことはできますが、ファイルは再ダウンロードが必要です。

### ダウンロードの仕組み

- 最大 3 並列でダウンロード（設定で 1〜3 に変更可）
- 通信断や一時停止からのレジューム対応（HTTP Range + file_id / サイズ / ETag で整合性検証）
- 失敗時は自動リトライ（設定のリトライ回数まで）
- 429/403 エラー時はエクスポネンシャルバックオフで待機

### 画質

設定画面で **Source**（最高品質）/ **540p** / **360p** から選択できます。

### 外部動画

iwara のページに埋め込まれた YouTube / Vimeo 等の外部動画は、yt-dlp を使ってダウンロードできます。デフォルトでは OFF で、設定またはチャンネル別に ON/OFF を切り替えられます。

## ツールメニュー

| メニュー | 説明 |
|----------|------|
| URL 一括インポート... | URL のリストをまとめて取り込み |
| iwara 検索インポート... | iwara の検索結果を取り込み |
| フォルダから取り込み... | ローカルフォルダの動画ファイルを DB に登録 |
| 重複チェック... | UUID やファイル情報に基づいて重複を検出 |
| 統計ダッシュボード... | ダウンロード統計の表示 |
| 未移動ファイルの一括移動... | 保存先変更時に移動できなかったファイルを再移動 |
| 移動済みファイルの再リンク... | 外部ツールで移動したファイルのパスを DB に追従 |
| ローカルファイル整合性チェック... | DB の記録と実ファイルの食い違いを検出 |
| DB操作ツール(上級者向け)... | [DB 操作ツール](Database-Tool) を起動（設定でオンにした場合のみ表示） |

## キーボードショートカット

| キー | 機能 |
|------|------|
| `F5` | 新着チェック |
| `Ctrl+D` | 選択動画をダウンロード |
| `Ctrl+F` | 検索ボックスにフォーカス |
| `Ctrl+A` | 全選択 |
| `Delete` | 選択動画を削除 |
