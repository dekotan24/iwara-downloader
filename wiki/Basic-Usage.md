# 基本的な使い方

## 画面構成

メイン画面は以下の要素で構成されています。

- **左側ツリービュー**: カテゴリ・チャンネル一覧
- **右側リストビュー**: 動画一覧（詳細リスト / サムネタイル表示に切替可）
- **上部**: URL 入力欄、検索ボックス、NSFW フィルタ
- **下部ステータスバー**: 現在の状態表示

### ツリービューのカテゴリ

| カテゴリ | 内容 |
|----------|------|
| 全ての動画 | 登録済みの全動画 |
| お気に入り | お気に入りに登録した動画 |
| ダウンロード中/待機中 | 現在 DL 中または DL 待ちの動画 |
| └ 未DL動画 | 完了・スキップ以外の動画 |
| └ DL済動画 | ダウンロード完了済み |
| └ スキップ動画 | スキップされた動画 |
| └ エラー一覧 | ダウンロード失敗した動画 |
| 単発動画 | チャンネル経由でなく個別に追加した動画 |
| (各チャンネル) | 購読したユーザーごとの動画 |

## チャンネル購読

URL 入力欄にユーザー名またはプロフィール URL を入力して Enter で追加します。

- `username` のみの入力でも可
- `https://www.iwara.tv/profile/username` 形式でも可
- `https://www.iwara.ai/profile/username` にも対応

追加すると動画一覧の取得が始まります。取得完了後、自動チェックが有効なら定期的に新着をチェックします。

### チャンネルの右クリックメニュー

| メニュー | 説明 |
|----------|------|
| ページを開く | iwara のプロフィールページをブラウザで開く |
| 今すぐ確認 | 新着を即座にチェック |
| 全てダウンロード | 未 DL の動画をすべてキューに追加 |
| Not Found を除外 | エラー一覧選択時のみ表示。404 動画を除外 |
| ファイル存在チェック | DL 済みファイルのローカル存在を検証 |
| 保存先を変更... | このチャンネル専用の保存先を設定 |
| iwara外動画のDL | YouTube 埋め込み等の DL 設定（デフォルトに従う / DLする / DLしない） |
| 有効にする / 無効にする | 自動チェックの対象にするかどうか |
| 削除 | チャンネル登録を削除 |

## ダウンロード

### 方法

- **チャンネルから**: 動画を選択して右クリック →「ダウンロード」
- **単発**: URL 入力欄に動画 URL（`https://www.iwara.tv/video/xxxxx`）を入力して Enter
- **クリップボード監視**: 設定で ON にすると、iwara URL をコピーするだけで自動追加
- **一括インポート**: ツールメニューから URL リスト / 検索結果 / ローカルフォルダから取り込み

### 動画の右クリックメニュー

| メニュー | 説明 |
|----------|------|
| ダウンロード | DL キューに追加 |
| キャンセル | DL 中のタスクを中止 |
| 失敗を再試行 | 失敗したタスクをリトライ |
| 再ダウンロード... | 完了済みの動画を再度 DL |
| 情報再取得 | タイトル等のメタ情報を iwara から再取得 |
| ファイル存在チェック | ローカルファイルの存在を検証 |
| 再生 | DL 済みファイルをデフォルトプレーヤーで再生 |
| フォルダを開く | ファイルの保存先フォルダを開く |
| ページを開く | iwara の動画ページをブラウザで開く |
| 投稿者のページを開く | 投稿者のプロフィールページを開く |
| URLをコピー | 動画の URL をクリップボードにコピー |
| タイトルをコピー | タイトルをクリップボードにコピー |
| ★ お気に入りに追加 | お気に入り登録のトグル |
| 詳細情報... | 動画の詳細情報（メタデータ、タグ、メモ）を表示・編集 |
| 削除 | DB から削除 |

### ダウンロードの仕組み

- 最大 3 並列でダウンロード（設定で 1〜3 に変更可）
- 通信断や一時停止からのレジューム対応（HTTP Range + file_id / サイズ / ETag で整合性検証）
- 失敗時は自動リトライ（設定のリトライ回数まで）
- 429/403 エラー時はエクスポネンシャルバックオフで待機

### 画質

設定画面で以下から選択できます。

- **Source**: 最高品質
- **540p**: 中品質
- **360p**: 低品質

### 外部動画

iwara のページに埋め込まれた YouTube / Vimeo 等の外部動画は、yt-dlp を使ってダウンロードできます。デフォルトでは OFF で、設定またはチャンネル別に ON/OFF を切り替えられます。

## インポート

ツールメニューから以下のインポート方法が使えます。

| メニュー | 説明 |
|----------|------|
| URL 一括インポート... | URL のリストをまとめて取り込み |
| iwara 検索インポート... | iwara の検索結果を取り込み |
| フォルダから取り込み... | ローカルフォルダの動画ファイルを DB に登録 |

## キーボードショートカット

| キー | 機能 |
|------|------|
| `F5` | 新着チェック |
| `Ctrl+D` | 選択動画をダウンロード |
| `Ctrl+F` | 検索ボックスにフォーカス |
| `Ctrl+A` | 全選択 |
| `Delete` | 選択動画を削除 |
