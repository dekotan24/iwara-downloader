# 検索・フィルタ

## 検索ボックス

画面上部の検索ボックスで動画を絞り込めます。

### 基本構文

スペース区切りで複数の語を入力すると AND 検索になります。各語はタイトル / 投稿者名 / タグ / メモのいずれかにマッチすれば一致とみなされます。

```
foo bar    → foo と bar の両方を含む動画
```

チャンネル選択中はフリーテキストが投稿者名を検索対象から除外します（作者名がノイズになるため）。

### フィールド指定

特定のフィールドに限定して検索できます。

| 構文 | 説明 |
|------|------|
| `tag:vr` | タグに「vr」を含む（`tags:` でも可） |
| `author:foo` | 投稿者名に「foo」を含む |
| `memo:推し` | メモに「推し」を含む |
| `status:failed` | ステータスで絞り込み |
| `fav:true` | お気に入りのみ（`favorite:` でも可） |
| `rating:nsfw` | レーティング指定 |
| `site:ai` | サイト指定（ai / tv） |
| `id:AbCdEfGh` | VideoId で検索 |
| `uuid:xxxxx` | FileUuid で検索 |
| `url:xxxxx` | URL で検索 |

### ステータス指定のエイリアス

`status:` にはエイリアスが使えます。正規のステータス名（`completed`, `downloading` 等）もそのまま使えます。

| 入力 | 対象ステータス |
|------|--------------|
| `done`, `ok` | 完了 (completed) |
| `wip`, `dl` | ダウンロード中 (downloading) |
| `err`, `error`, `fail` | 失敗 (failed) |
| `wait`, `queue` | 待機中 (pending) |
| `skip` | スキップ (skipped) |
| `pause` | 一時停止 (paused) |

### 除外・フレーズ

| 構文 | 説明 |
|------|------|
| `-bot` | 「bot」を含むものを除外 |
| `"two words"` | 引用符内をひとまとまりとして検索 |

## NSFW フィルタ

画面上部のドロップダウンで表示する動画のレーティングを切り替えられます。

| 選択 | 表示対象 |
|------|----------|
| All | すべて（デフォルト） |
| SFW | `general` のみ |
| NSFW | `ecchi` のみ |

## 表示モード

動画リストは 2 つの表示モードを切り替えられます。

- **詳細リスト**: 列でタイトル・投稿者・ステータス等を一覧表示
- **サムネタイル**: サムネイル付きのタイル表示

サムネイルは自動で取得・キャッシュされます。
